# Mira and the Little Wonders

Original stylized 3D children's animation project.

## Production order
1. **First:** 15–20-second actual animated character test with Mira, Ollo and Kiri.
2. **Then, after approval:** Episode 1, *The Bridge That Bent* (target 4:30, 1920x1080, 24 fps).

**Codex assignment:** https://github.com/Hayk0720/mira-little-wonders/issues/1

## Local setup
Open this repository in VS Code with Codex. Supply the approved character images and `Mira_Ollo_Kiri_Series_Bible_v1.md` locally to the workspace. These references are not included in this public repository.

Run Codex with this instruction:

> Read GitHub issue #1. Inspect the local reference files and Blender installation. Build the editable Blender 15–20 second interaction test, render a genuine animated MP4, review first/middle/last frames, and create QA reports. Do not stop after planning. Do not claim primitive placeholders are final character designs.

Blender launcher supplied by project owner: `C:\Program Files\Blender Foundation\Blender 5.2\blender-launcher.exe`. Find the actual `blender.exe` inside the installation for background scripts.

This repository is currently public. Do not push private/unpublished reference images without explicit approval.
